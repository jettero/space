# Space Station Map Assets

This folder contains text-exported `Map` layouts that can be round-tripped via `space.map.io`.

## Current Maps

- `station1.map` – Octagonal station (`room_kind="bay"`): an octagonal hull ring around a central octagonal hub, eight radial spokes (n/s/e/w axis lines + ne/nw/se/sw exact-45° lines), with rectangular rooms seated flush against the ring.
- `station2.map` – Octagonal station (`room_kind="module"`): the same skeleton, but the rectangular rooms detach outside the ring, each reached by an extended spoke.

Both files are generated by `generate_station` in `space/map/generate/toroid.py`. The geometry is grid-native — every wall edge is axis-aligned or an exact 45° diagonal — so the hull renders cleanly as box-drawing (`─│` and `╱╲`) with no `░` gaps.

### Re-generating

Run from the project root:

```sh
python - <<'PY'
from space.map.generate.toroid import generate_station
from space.map import export_map_to_path

export_map_to_path(generate_station(room_kind="bay"), "asset/station1.map")
export_map_to_path(generate_station(room_kind="module"), "asset/station2.map")
PY
```

### Loading Into Code

```python
from space.map import import_map_from_path

station_map = import_map_from_path("asset/station1.map")
# use station_map like any Map, e.g., iterate cells or drop objects
```

To load the module layout replace the path with `asset/station2.map`.
